## 1. 简介

AutoCinema 是一款基于 AI 的全自动视频生成工具。您只需输入一段简单的故事文本，它就能自动帮您：
- ✍️ **改写剧本**：将故事拆分为分镜脚本。
- 🎨 **绘画**：为每个分镜生成画面。
- 🗣️ **配音**：生成旁白语音。
- 🎬 **剪辑**：自动合成视频并添加字幕。

## 2. 安装与启动

### 前置条件
确保您的电脑上已安装 .NET 8.0 运行时。

### 启动步骤
1. 打开 `AutoCinema` 文件夹。
2. 双击运行 `AutoCinema.Desktop.exe`（或在命令行输入 `dotnet run` 启动）。

*首次运行时，请确保已在配置文件或设置中填写了正确的 API 密钥。*

## 3. 主界面概览

启动后，您将看到简洁的主界面：

- **左侧导航栏**：
  - 🏠 **主页**：查看最近的项目列表。
  - ➕ **新建项目**：开始一个新的视频生成任务。
  - 📋 **任务队列**：查看批量任务的通过状态。
  - ⚙️ **设置**：配置 API 密钥和偏好。

## 4. 创建单个视频项目

1. 点击 **"新建项目"**。
2. **输入标题**：为您的视频起个名字。
3. **输入故事**：在文本框中粘贴或输入您的故事内容。
4. **高级选项** (可选)：
   - **视觉风格**：描述画面的风格（如：电影感、二次元、水墨画）。
   - **角色描述**：描述主角的形象（如：一只戴着红色围巾的小白猫）。
5. 点击 **"生成视频"**。
6. 等待进度条完成，完成后可直接播放或打开文件夹。

## 5. 批量视频生成

如果您有多个故事需要生成视频，可以使用批量功能，让电脑自动排队处理。

### 添加任务到队列
1. 在创建项目时，选择 **"添加到队列"** 而不是直接生成。
2. 您可以连续添加多个项目。

### 管理任务队列
1. 点击左侧导航栏的 **"任务队列" (📋)** 图标，打开 **任务队列管理器**。
2. **功能按钮**：
   - ▶ **开始队列**：开始自动处理队列中的任务。
   - ⏸ **暂停**：暂停当前队列（当前正在处理的任务会继续直到完成）。
3. **任务列表**：
   - 查看每个任务的状态（等待中、进行中、已完成、失败）。
   - 查看实时进度百分比。
   - 点击 **"打开"** 查看已完成的视频。
   - 点击 **"❌"** 移除不需要的任务。

## 6. 设置

在设置页面，您可以配置 AI 服务的密钥：

- **火山引擎 (Volcengine)**：用于故事改写 (LLM) 和 AI 绘画。
- **MiniMax**：用于 AI 配音。

请确保密钥填写正确，否则无法生成内容。

## 7. 常见问题

**Q: 生成失败怎么办？**
A: 请检查网络连接和 API 密钥余额。如果是暂时性错误，您可以尝试重新提交任务。

**Q: 视频生成在哪？**
A: 默认保存在程序目录下的 `output` 文件夹中。

**Q: FFmpeg 未找到？**
A: 确保 `src/ffmpeg` 目录中包含 `ffmpeg.exe`，或者您的系统环境变量中已安装 FFmpeg。
